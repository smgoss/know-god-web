feat: Add comprehensive conditional visibility system for lesson quizzes

🎯 MAJOR FEATURE: Conditional Visibility for Interactive Lessons

This commit implements a complete conditional visibility system that enables
lesson quizzes to show/hide content based on user interactions and state values.

## 🚀 Core Features Added:

### 1. VisibilityWatcherService
- Central service managing component visibility state
- Supports both 'gone-if' (DOM removal) and 'invisible-if' (hidden) conditions
- Memory-safe watcher lifecycle management
- Style merging with existing component styles

### 2. Component Integration
- **Button Component**: Buttons disappear after quiz answer selection
- **Paragraph Component**: Result paragraphs show/hide based on answers
- **Text Component**: Individual text elements support conditional visibility
- All components implement VisibilityWatcherComponent interface

### 3. Template Updates
- *ngIf directives for 'gone-if' conditions (complete DOM removal)
- ngStyle directives for 'invisible-if' conditions (hidden but space preserved)
- Service integration for visibility state management
